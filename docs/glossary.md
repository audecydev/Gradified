# Glossary

| Term | Meaning |
|---|---|
| Academic authority | Current, school-approved facts defining what may be graded and how. |
| OCR evidence | Observed answer blocks, positions, states and source metadata; not approval. |
| Criterion | One mark-bearing statement in an approved rubric. |
| Judgment | An evaluator's structured finding about a criterion and its evidence. |
| Candidate score | Engine-calculated result not yet an official released grade. |
| Original operation | Stable request identity used to relate effects, regrades, retries and reconciliation. |
| Conditional write | A durable operation accepted only when exact approved identity and current state still match. |
| Regrade | Separately authorized re-evaluation tied to a previous original. |
| Retry | Recovery-directed attempt with proof that it is permitted; not an untracked duplicate. |
| Unknown outcome | An effect may have happened but the client has no conclusive acknowledgment. |
| Review decision | An authenticated teacher's recorded decision; not automatically an official result revision. |
| Official release | Backend-authorized publication after separate policy, audience and original-intent checks. |
| Provider physical event | Actual transport/usage evidence belonging to a specific original attempt. |

Exact Python object names are listed in [Integration ports](integration_ports.md) and [Source reference](source_reference.md).
