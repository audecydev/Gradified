# Remaining grading breadth and integration work

The published Release 1 source baseline is commit `41fd7756a37e446a79051f349629f1fc514f2991`. It is qualified for the supported subset described in [Capabilities and limitations](capabilities_and_limitations.md); its full Windows/property source regression is complete. The following is the **next-development** sequence, not evidence that missing breadth is implemented.

## One active grading capability at a time

1. School-authored question/model answer → proposed rubric with versioned, teacher-controlled approval.
2. Same-paper CHOICE+DIRECT+NUMERIC under one attempt, accounting and conditional score commit.
3. Teacher-authorized revised official result with recomputed paper totals, immutable lineage and guarded release.
4. Bounded unit-aware numeric evaluation with explicit conversions and fail-safe uncertainty.
5. Safe mathematical working/equivalence and approved alternative methods backed by exact reference provenance.
6. Separate OCR/rubric/evaluation confidence and academically calibrated teacher-review routing.
7. Bounded diagram/table/structured-answer evaluation for explicitly supported, validated subtypes.
8. Criterion/source-grounded academic error classification, feedback and grievance handling.

For each capability: inspect exact SRS and existing source/tests; define supported, unsupported and uncertain outcomes; implement the smallest coherent vertical path; run targeted positive and adverse tests; update affected docs; then close and move to the next. Preserve frozen scoring, trusted authority, source identity, original-keyed attempts, CAS and conditional release. No speculative general grading framework.
