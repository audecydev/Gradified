# Remaining integration work

The following sequence is ordered by dependency, not by internal development milestone.

1. **Exact-source verification:** run the complete regression and property suites on the installed candidate and record the Git content tree and environment.
2. **Backend authority:** connect authenticated school, teacher, paper, current policy and rubric issuers to installed source interfaces.
3. **OCR and references:** demonstrate real scans, complete question mapping, approved reference versions and uncertain evidence handling.
4. **Provider and storage:** connect canonical model transport, physical usage receipts, original-keyed conditional attempts and scored-result CAS to real infrastructure.
5. **School operation:** grade a supported real paper; test FIRST, REGRADE, RETRY, teacher journal, safe feedback and separately authorized release.
6. **Adversarial qualification:** cross-tenant, stale-source, duplicate-worker, timeout, revoked-issuer and restart campaigns.
7. **Academic scope:** make explicit feature decisions and develop or block unit-aware mathematics, derivations, diagrams, arbitrary mixed exams, corrected official mark projection and calibrated automatic review.

Do not substitute simulation evidence for a real school or provider sign-off. The [Integration test plan](integration_test_plan.md) defines the operational acceptance record.
