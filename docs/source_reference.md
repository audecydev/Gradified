# Python source reference

This index lists **every non-private top-level class, function and named assignment** declared in the 113 installed production Python modules. It includes 849 declaration names. The inventory is extracted from the source syntax; it is not a list of supported public APIs, a promise of long-term compatibility, or evidence that any external backend/provider adapter is deployed. Source modules, not this index, define exact signatures, field types and exceptions.

For integration entry points, begin with [Integration ports](integration_ports.md) and [Port signatures](port_signatures.md). For runnable examples, use [Production wiring](deployment_wiring_walkthrough.md). Consumers must import current names from the installed source; names found in older development bundles are not aliases.

**Index scope:** top-level public-looking declarations only. Private names beginning with `_`, methods, nested classes and names imported from another module are intentionally excluded. Module-level constants are listed because their spelling may be relevant to source inspection; their presence here does not make them school-authorized configuration.
